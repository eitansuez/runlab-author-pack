# Tutorial

The pack comes with three finished labs. Each page in this section opens one of them and walks through its files, so you can see how a lab is put together before you write your own.

- [basics](basics.md) is the smallest lab: a title, a description, and a lesson.
- [docker](docker.md) is the same kind of lab, and its lesson uses Docker, which is already on the machine.
- [nginx](nginx.md) installs a web server while its disk is built, so nginx is already running when the lab opens.

Each lab is a directory that sits next to `trylab`, and the directory's name becomes the lab's name. Stick to letters, digits, and hyphens, and avoid `default`, which is reserved for the shared disk.

Take them in order. Each page builds on the one before.
