# Prepare the machine

When a lesson needs software that isn't on the shared disk, you install it while the lab's disk is built. A snapshot can then save the running machine, so the program is already up when the lab opens.

The [nginx](tutorial/nginx.md) page in the Tutorial walks through all of it: `setup.sh`, the `data` directory, the lab's own disk, the story and its snapshots, and links to a page the machine is serving.
